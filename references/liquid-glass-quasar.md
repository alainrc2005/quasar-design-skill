# Liquid Glass in Quasar

> Curated guide — not generated by the HIG pull script.

Apple's Liquid Glass material (introduced in visionOS 2, extended to iOS 26 and macOS 26) uses a
translucent, lightly tinted surface with a subtle inner glow. In Quasar apps this is achieved with
CSS `backdrop-filter` and carefully chosen semi-transparent backgrounds.

## Core CSS Recipe

```css
.liquid-glass {
  background: rgba(255, 255, 255, 0.72);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border-radius: 12px;
  border: 1px solid rgba(255, 255, 255, 0.3);
  box-shadow:
    0 0 0 0.5px rgba(0, 0, 0, 0.05),
    0 2px 8px rgba(0, 0, 0, 0.06);
}

.dark .liquid-glass {
  background: rgba(58, 58, 60, 0.72);
  border: 1px solid rgba(255, 255, 255, 0.1);
  box-shadow:
    0 0 0 0.5px rgba(0, 0, 0, 0.2),
    0 2px 8px rgba(0, 0, 0, 0.15);
}
```

## Where to Apply It

Apple restricts Liquid Glass to the **floating functional layer**:

| Layer | Use Liquid Glass? | Quasar component |
| --- | --- | --- |
| Tab bar (floating) | Yes | Custom `QTabs` with glass class |
| Toolbar (translucent) | Yes | `QToolbar` with glass class |
| PageSticky bottom bar | Yes | `QPageSticky` + glass class |
| Dialog / Sheet backdrop | No — use opaque or lightly tinted | `QDialog` background |
| Cards, lists, content areas | No — use solid surfaces | `QCard`, `QList` backgrounds |
| Page background | No — use system color | `q-page` default |

## Component-Level Patterns

### Glass Tab Bar

```vue
<template>
  <div class="glass-tab-bar">
    <q-tabs v-model="tab" dense active-color="primary" indicator-color="transparent">
      <q-route-tab name="home" label="Home" icon="home" />
      <q-route-tab name="search" label="Search" icon="search" />
      <q-route-tab name="profile" label="Profile" icon="person" />
    </q-tabs>
  </div>
</template>

<style scoped>
.glass-tab-bar {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  z-index: 100;
  padding-bottom: env(safe-area-inset-bottom, 8px);
}

.glass-tab-bar :deep(.q-tabs) {
  background: rgba(255, 255, 255, 0.72);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border-top: 1px solid rgba(255, 255, 255, 0.3);
}

.dark .glass-tab-bar :deep(.q-tabs) {
  background: rgba(58, 58, 60, 0.72);
  border-top: 1px solid rgba(255, 255, 255, 0.1);
}
</style>
```

## Review Checklist

- [ ] Glass is applied only to floating functional layers (bars, tab bars)
- [ ] Content areas use solid surfaces, never glass
- [ ] `backdrop-filter` has `-webkit-` prefix for Safari compatibility
- [ ] Fallback background color exists if backdrop-filter fails
- [ ] Reduced transparency setting is respected (solid fallback in `prefers-reduced-data`)
- [ ] Contrast meets WCAG AA with the semi-transparent background
- [ ] Dark mode variant uses darker translucent backgrounds
- [ ] Inner glow / border adds subtle depth without decoration

## Cross-Platform Notes

| Target | Backdrop filter support | Fallback strategy |
| --- | --- | --- |
| SPA (modern browsers) | Full | `-webkit-` prefix covers Safari |
| PWA | Full (PWA in browser context) | Same as SPA |
| Capacitor (iOS 13+) | Full on iOS 13+, partial on older | Solid translucent background |
| Capacitor (Android) | Full on Android 7+ | Solid translucent background |
| Electron | Full (Chromium-based) | Same as web |

## Reduced Transparency

When the user enables "Reduce Transparency" (iOS) or equivalent, disable glass effects:

```css
@media (prefers-reduced-transparency: reduce) {
  .liquid-glass {
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
    background: rgba(246, 246, 247, 0.95);
  }
  .dark .liquid-glass {
    background: rgba(30, 30, 30, 0.95);
  }
}
```
